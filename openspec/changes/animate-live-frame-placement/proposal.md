# Animate live frame and input transitions

Add motion, Fade and duration for frame placement changes made with **Update on air**. Operators
can use Fade on its own or combine it with movement. A live preset switch can use the same
effect to carry a shared authored plate from its outgoing placement to the incoming placement.
Animate departing and arriving plates, with shared plates above departing plates during motion.
Run the preset effect in PVW and keep direct gestures immediate. Add Cut and Fade for one
plate's source change and Bounce and Elastic for frame motion. Keep a masked plate's input
framing fixed while leaving its mask editable.
