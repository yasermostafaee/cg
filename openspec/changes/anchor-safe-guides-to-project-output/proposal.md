# Anchor Designer safe guides to the project output

## Why

A cropped subtitle or logo composition needs the same broadcast reference as the other compositions in its project. Sizing the guides from a cropped composition places the safe areas inside the crop.

## What changes

- Save an independent Designer project output raster with a 1920×1080 default.
- Show the composition's position inside that raster and provide a separate fit command.
- Author an output anchor and position for each standalone composition with the existing playout placement contract.
- Fit the project-sized checkerboard and placed composition in the dedicated Designer Preview.
- Keep composition dimensions, nesting transforms, and guide appearance preferences independent.
