## ADDED Requirements

### Requirement: The local preview combines the current Designer and reviewed gallery

The local Designer preview SHALL expose the owner's latest accepted browser authoring contracts
together with the reviewed starter gallery. Integration SHALL preserve unrelated original work and
SHALL be verified against the merged source snapshot before being presented as current.

#### Scenario: The owner opens the refreshed Designer

- **WHEN** the integrated bundle has been rebuilt and the local Designer page is refreshed
- **THEN** Landing provides the current project-import action and revised Persian starter gallery
- **AND** opening a starter uses the current Preview, Inspector, Variables and Preset interfaces
- **AND** the gallery's reviewed content and lifecycle behaviors remain intact

#### Scenario: Current authoring and gallery features coexist

- **WHEN** the author opens the revised league, weather, Azan or multi-Preset example
- **THEN** its ordinary fields, row effects, timing, Steps and Presets remain editable through the
  latest Designer surfaces without restoring the older shell or losing authored gallery settings

#### Scenario: The owner's work is preserved

- **WHEN** current Designer changes are reconciled with gallery work
- **THEN** the original owner checkout and supplied projects remain unmodified by that integration
- **AND** native/installer and CG Control-only unfinished work is not implicitly adopted or completed

#### Scenario: Validation refers to the integrated snapshot

- **WHEN** the integrated preview is reported ready
- **THEN** the current merged source has its own build and real-browser validation evidence
- **AND** earlier source-branch gate or browser results are identified as historical rather than
  claimed as proof for this combined revision
