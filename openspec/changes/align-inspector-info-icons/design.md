# Design

Help is a fourth grid item for action rows and a third grid item for ordinary value rows. Section
state lines already put their optional tip last, so the same structural rule applies everywhere:
the info button is the final direct item of its row. Fixed icon columns align the glyphs without
changing the width or semantics of labels and actions. State lines explicitly fill the available
width instead of inheriting the prose measure; otherwise their final item stops several pixels short
of the fixed row column.
