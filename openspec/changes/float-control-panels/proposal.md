## Why

Operators can give a programme or preview monitor a second display and keep the controls on another one.

## What Changes

- Detach each workspace panel into a window in the Windows desktop app.
- Give detached monitors independent maximize and restore. Their windows contain the monitor and its controls.
- Provide Exit floating to put the panel back in the main window. Preserve the shared session, selected row, drafts and live previews while panels move.
- Scope the main toolbar's show and hide toggle to docked monitors.
- Include positions, sizes and detached state in local UI profiles.

## Capabilities

- Modified capability: `control-workspace-layout`.

## Impact

CG Control's Windows window handling, workspace, monitor previews, Inspector selection and local UI profiles.
