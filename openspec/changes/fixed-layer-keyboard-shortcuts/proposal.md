# Fixed layer keyboard shortcuts

Operators can assign shortcuts to Play, Next, Stop and Clear on declared layers. Layers 99 through
88 receive F1 through F12 defaults on channels without saved bindings. The Layer shortcuts
dialog saves and reverts its own edits. Layer settings show
the same names and aliases as the layer table. The Bridge stores the assignments with the bank.

The console uses physical key codes so bindings work with Persian and English keyboard layouts.
Pressing an assigned shortcut invokes the matching row control with its current permissions,
availability and confirmation.
