# Fixed layer keyboard shortcuts

Operators can assign shortcuts to Play, Next, Stop and Clear on declared layers. Layers 99 through
88 receive F1 through F12 defaults on channels without saved bindings. Space can be assigned
manually. The Layer shortcuts dialog saves and reverts its own edits. It lists each layer number
before its name and translates the action headings into the interface language. The Bridge stores
the assignments with the bank.

The console starts with shortcuts off. A switch in Layers and in the shortcuts dialog controls
the current console session, including detached panels. An assigned key pressed with shortcuts
off points the operator to the switch in Layers. The console uses physical key codes.
With the switch on, pressing an assigned shortcut invokes the matching row control with its
current permissions, availability and confirmation.
