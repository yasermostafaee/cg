# Place an authored live frame from Preview

Group Fit, movement and resize in Designer under **CG Control** for one or several live plates.
Allow the author to grant frame movement and resizing independently. In CG Control the operator
can draft the permitted moves and resizes in PVW. For a frame whose author allows the operator
to choose its ratio, **Preserve aspect ratio** in Inspector starts on. **Crop input** remains the
source selection inside the frame.

In Designer, extend the existing **Auto layout** to visual timeline selections. Include child
compositions containing a live frame and its title so authors can arrange and swap them while
editing a preset. The same controls work for mixed selections such as a plate, a composition,
a shape and a Repeater. In CG Control, the available layouts and settings follow each preset
separately. Choosing an Arrangement or editing a valid gap reflows that preset in PVW. Allow frame edits on
the running page after a template replacement when the live frame layout remains compatible.

Place Auto layout permission in the composition Inspector for each registered preset. Preserve
legacy permissions for existing templates and show the authoring permission required when CG
Control cannot arrange an authorized multi-frame preset.
