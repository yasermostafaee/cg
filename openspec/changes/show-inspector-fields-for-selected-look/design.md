## Ownership and selection

The selected Look follows the active Look until the operator chooses a tab in Inspector. The same selection drives Look inputs and the field list. The VCG Look carrier exposes the managed composition's instance ID. Inspector matches that ID to the top-level dynamic field group and its descendants. Root-owned fields and groups outside the managed Looks are shared. Names, order and source IDs play no part in ownership.

Filtering only changes which editors are rendered. All values continue to use the row's existing draft, Update and Discard paths. The instance ID is optional in the catalogue protocol. For an incomplete catalogue, read the Bridge's retained page for the same template and channel. Parse its embedded scene JSON without executing the page. Use the page map only when it agrees with the catalogue's Looks, known instance IDs and composition groups. If that evidence is absent or inconsistent, keep all groups accessible. An updated Bridge carries the IDs directly.
