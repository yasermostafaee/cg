Both authoring surfaces use the same picture picker and asset store as Add. A replacement fills the existing picture slots in natural file order, appends any overflow, and removes unfilled picture slots. Text and composition items keep their order and their place relative to picture slots. A cancellation, an empty selection, or a failed image import leaves the sequence intact. Apply the completed replacement through the existing sequence setter and history entry so bound defaults track it and Undo restores the old items.
