## ADDED Requirements

### Requirement: Newer-template refusal SHALL name CG Control

CG Control SHALL name itself as the product that needs updating when an imported template requires
a newer rendering contract than the station provides. The refusal SHALL identify both versions and
retain update and matching-Designer re-export recovery actions.

#### Scenario: A newer template is imported

- **WHEN** the template requires a newer rendering contract than the station provides
- **THEN** the refusal says the template needs a named CG Control version
- **AND THEN** it names the installed version and offers update or matching-Designer re-export
