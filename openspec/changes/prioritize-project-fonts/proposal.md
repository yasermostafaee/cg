## Why

Project fonts currently appear below the built-in families, so designers have to scroll past the default list to find a font they just imported.

## What Changes

- Show the existing Project fonts group first in the Inspector's font family picker.

## Capabilities

### Modified Capabilities

- `designer-inspector`: order the common font family picker with project fonts first.

## Impact

- CG Designer's Text, Ticker, Clock and Sequence inspectors.
