The checkerboard is the background of the Canvas iframe stage. When Stop finishes the Outro, the runtime marks the document body pending. The shared CSS makes the body transparent and hides the stage. The main Canvas restores body and stage opacity in its cleared rehearsal state and hides the artwork inside the stage. The dedicated Preview and exported playout retain the runtime defaults. The regression samples both checker colors from a browser screenshot after Stop so it detects opacity on ancestor elements.
