## Why

Panel programmes need quick layout authoring and focus changes in the same console that runs them.

## What Changes

- Add a Live layout editor and duplicate action to the CG Control catalogue.
- Start with an empty layout and author frames, preset membership, arrangements, title visibility and an optional background.
- Bind reusable VCG artwork to its frame across presets and Focus so it shares the frame transition.
- Configure and rehearse motion and solo-to-solo effects once per layout from the Plate tab.
- Name Focus controls and place each frame in the desired position of each preset.
- Style one or more texts per frame with shared styles, overrides, packaged fonts and digit sets.
- Author optional frame fit, placement permissions and masks in the advanced frame controls.
- Add independent PVW Focus and explicit programme Focus and Return.

## Capabilities

### New Capabilities

- `runtime-author-live-layouts`: author and operate CG Control live layouts.

## Impact

CG Control catalogue, preview and Layers, the shared scene and IPC schemas, and CG Bridge's template and preset operations.
