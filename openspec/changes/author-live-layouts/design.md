## Authoring and persistence

Compile one standard VCG package with an optional authoring record, stable reusable frame
compositions, scoped presets and packaged media. Use the same verified package, page, catalogue
and source retention as an imported template. A saved copy has a fresh template identity.
Editing checks that the displayed version is still current and off air. A separate layout can
be authored and saved while a row holds its existing output.

## Focus and Return

Compile registered single-frame destinations for each origin preset and frame. Keep the origin
preset in the destination identity and resolve its input bindings for Focus. Return selects the
same origin with its already stored placement, crop and title state. Both frame motion and a
directional change use the existing guarded preset paths. Preview retains its browser-only cue.
The row's applied look remains the authoritative programme state.

## Layout settings

Use the shared Auto layout calculations. Presets store their own arrangement, membership,
ordering and spacing. Transition settings are shared by all presets in the saved layout.
