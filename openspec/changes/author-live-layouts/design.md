## Authoring and persistence

Compile one standard VCG package with an optional authoring record, stable reusable frame
compositions, scoped presets and packaged media. Use the same verified package, page, catalogue
and source retention as an imported template. A saved copy has a fresh template identity.
Editing checks that the displayed version is still current and off air. A separate layout can
be authored and saved while a row holds its existing output.

## Focus and Return

Compile registered single-frame destinations for each origin preset and frame. Keep the origin
preset in the destination identity and resolve its input bindings for Focus. Return selects the
same origin with its already stored placement, crop and title state. Both frame motion and a
directional change use the existing guarded preset paths. Preview retains its browser-only cue.
The row's applied look remains the authoritative programme state.

## Layout settings

Use the shared Auto layout calculations. Presets store their own arrangement, membership,
ordering and spacing. Selecting a numbered position swaps the two frames in that preset's
effective order, including while Reverse is enabled. Focus labels live on the shared frame and
its stable identifier travels on Preview and Programme commands. Transition settings are shared by all presets in the saved layout.
Cut swaps the already-seated solo plate directly. Fade blends two stationary, full-frame seats
before committing the target. Both retain the same Return destination.

The shared title style supplies defaults for all frames. A frame can override individual properties.
Position and box dimensions are relative to the frame so titles scale with the frame composition.
The compiler uses the fixed text renderer for glyph positioning, wrapping, borders and shadows.
Added font files travel with the saved VCG and appear first in the font list. Older frame styles
remain readable as overrides. Digits use the existing Designer text and binding notation so the
chosen set applies to the authored title and later operator values. Each additional text has its
own stable binding and inherits the frame title style before applying its own override.

Frame fit, Move, Resize and mask settings are authoring options on the shared frame. Compilation
gives the existing PVW operations the same permissions and mask metadata as a Designer plate.
The normal preset and Focus look reference the same frame definition.

The editor and browser PVW honor the saved broadcast effect when rehearsing a Focus change.
Keep the editing selection distinct from the temporary focus on the rehearsal canvas.
