## Decisions

- Positions use physical left and right. The starting order is Preview, then Programme; monitors above Layers; Inspector on the right.
- Reposition retained panels with layout rules so an active Preview does not reload when another pane moves. Resize direction follows the displayed edge. Use the selected physical side for the narrow Inspector overlay.
- Save named UI profiles with current positions and panel sizes together in the existing browser-local shell layout record. Keep old records readable and retain the session visibility and fullscreen behavior. Keep UI profiles independent from station and layer profiles.
- Offer New live layout in Templates. Remove the duplicate action from the Layers header.
