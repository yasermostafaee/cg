## Why

Broadcast workstations differ in which physical side makes each panel easiest to reach.

## What Changes

- Add three independent panel position settings under Settings → General.
- Save named UI workspace profiles with positions and panel sizes on the workstation.
- Consolidate the creation entry point for live layouts in Templates.

## Capabilities

### New Capabilities

- `control-workspace-layout`: local workspace rearrangement and profiles.

## Impact

CG Control settings, workspace renderer, and browser-local shell layout state.
