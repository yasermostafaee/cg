# Design

The existing independent reserve session warms D10 outside playout verbs. A cached source is
eligible only with a canonical epoch, a unique local `playlistOf` row, `available=true`, a
layer-qualified route below CG's layer band, an explicit compatible mapped destination, and
a matching D4 video mode. A's producer address is never reused as B's producer address.

The reserve LOADBG and bare PLAY pass the normal command seam and B destination/layer guard.
A narrow pinned replica operation carries the already guarded B-local line without generic
route translation or journaling. The queue checks the source proof again at dispatch. The
proof holds both sessions, queues, the B connection generation, independent session token,
API address, source epoch/producer, and source/destination channel mappings.

A reconnect invalidates both the cached answer and in-flight reads. A late older response
cannot replace a fresh epoch. Existing route seats join peer geometry/preset motion only while
their source proof remains current and OSC confirms route producers on both occupied seats.

If proof is absent or stale, no B route is guessed, and the row retains the reserve warning.
The primary's existing route pair and silent Playlist audio policy remain in force.

Normal Take already seats the union of authored preset sources, including hidden plates.
Consequently a Playlist present only in a later preset is prepared hidden on both engines
before its first reveal. Dynamic on-air source replacement through an A-only input-effect
pre-seat remains excluded until an independent B hidden-seat transaction is available.
