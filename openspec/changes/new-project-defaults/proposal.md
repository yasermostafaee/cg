## Why

D-208: authors repeatedly enter the same raster, frame rate and duration when the shipped defaults differ from their station workflow.

## What Changes

- Let authors save New project defaults for name, resolution, custom dimensions, frame rate and duration.
- Put the settings in the New project dialog and in Designer's Edit menu.
- Keep one-off project values separate from the defaults.

## Capabilities

- `designer-shell`: configurable author preferences for New project.

## Impact

Designer shell and local author preferences. Project files and creation IPC keep their existing format.
