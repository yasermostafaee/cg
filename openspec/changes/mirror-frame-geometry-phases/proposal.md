## Why

An operator's animated frame resize or move reaches the active server, then the reserve receives only the settled geometry. During the effect the paired pictures differ.

## What Changes

- Reuse the existing preset movement transaction for eligible same-look frame geometry effects on current paired pages.
- Carry native easing, deferred commits and artwork phases to an independently proven resident peer.
- Preserve the existing recovery, quarantine and refusal rules, including isolation of unrelated same-kind reserve producers.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `runtime-caspar-bridge`: Mirrored resident geometry effects use the established peer transaction.

## Impact

The existing on-air geometry path and paired integration tests. Older pages without the required preset transition marker retain their existing behavior. No arbitrary route mirroring or managed External CG v2 writer is introduced.
